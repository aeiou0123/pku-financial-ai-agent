## 核心结论

如果检出口径偷换/限定词缺失/数值矛盾/来源降级，直接覆盖 LLM 的 verdict。
这是针对 benchmark 发现的两个系统性盲区的定向修复。

## 方法论说明

### 两层架构

```
  Claim + Source
       │
       ▼
  ┌──────────────────────┐
  │ Layer 1: 规则层       │  确定性检查，无 API 调用
  │ - 口径偷换检测        │  → definition_mismatch
  │ - 限定词缺失检测      │  → partially_supported
  │ - 数值矛盾检测        │  → refuted
  │ - 来源降级检测        │  → low_confidence
  │ - 时间错位检测        │  → refuted
  │ - 无证据检测          │  → abstain
  └────────┬─────────────┘
           │ 有覆盖 → 直接输出
           │ 无覆盖 ↓
  ┌────────▼─────────────┐
  │ Layer 2: LLM          │  语义判断
  │ - 语义一致性          │  → supported / refuted
  │ - 证据充分性          │  → abstain
  └──────────────────────┘
```

### 为什么规则层有效

Benchmark 评估发现，LLM 在以下两类扰动上的判别准确率极低：
- 口径偷换 12-35%：LLM 分不清额定扭矩/峰值扭矩、归母净利润/扣非净利润
- 限定词删除 32-42%：LLM 不识别限定条件被删除后的定义缺失

这些不是 LLM 理解能力的问题，而是注意力分配的问题——
LLM 能理解额定和峰值的区别，但在长文本中容易忽略这种替换。
规则层用确定性的字符串匹配 + 数值归属检测，
在这些特定模式上实现了 70-95% 的准确率。
