## 五、通用搜索技巧

### 5.1 公告搜索
1. 巨潮资讯网搜索框输入公司名
2. 选择"公告"分类
3. 按时间排序，重点看 2024–2025 年
4. PDF 中用 Ctrl+F 搜关键词："扭矩"、"人形"、"产能"、"募投"、"机器人"

### 5.2 datasheet 搜索
1. 公司官网"下载中心"或"产品中心"
2. 百度搜索：`公司名 filetype:pdf`
3. 行业公众号文章中的参数截图

### 5.3 专利搜索
1. Google Patents 搜公司英文名 + 产品关键词
2. CNIPA 搜公司中文名 + 产品关键词
3. 关注 2023 年以后公开的专利

### 5.4 研报搜索
1. Wind 终端输入股票代码，查看"研究报告"
2. 东方财富网研报中心
3. 慧博投研

## 六、数据口径注意事项

### 扭矩密度/功率密度的常见口径差异

| 口径 | 含义 | 可比性 |
|---|---|---|
| 额定扭矩密度 | 额定扭矩 / 重量 | 高 |
| 峰值扭矩密度 | 峰值扭矩 / 重量 | 高（但需标注） |
| 电机本体扭矩密度 | 不含减速器 | 与关节模组不可直接比 |
| 关节模组扭矩密度 | 含减速器、电机、编码器 | 与电机不可直接比 |
| 连续工况 | 长时间运行 | 与峰值不同 |
| 峰值工况 | 短时过载 | 与连续不同 |

**这正是 Claim Verification 要识别和标注的问题。**

## 七、数据整理要求

### 7.1 当前阶段的证据优先级

1. **P0**：绿的谐波财务模型所需的年报字段、明确页码/表格位置，以及一个可复现的本地 evidence fixture。
2. **P1**：Claim 的原文摘录、来源、页码/定位、口径和核验结论，优先覆盖绿的谐波主案例。
3. **P2**：官方 datasheet、步科发明专利、重大事项公告、BOM 和其他公司案例扩展。

已有研报参数可用于原型和候选证据，但若缺少原始定位或口径说明，不应在报告中升级为“已核实事实”。

每份资料必须配 `.meta.json`：

```json
{
  "filename": "buke_2024_annual_report.pdf",
  "title": "步科股份2024年年度报告",
  "source": "巨潮资讯网",
  "url": "https://www.cninfo.com.cn/...",
  "date": "2025-04-25",
  "collector": "西交经济金融",
  "company": "步科股份",
  "claim_type": "产能/需求",
  "notes": "包含2024年机器人业务收入、无框力矩电机出货量"
}
```

## 八、快速验证清单

每找到一个 claim，先问自己：

1. **Claim 主体是什么？**（公司、产品、参数）
2. **比较基准是什么？**（上一代、竞品、行业平均）
3. **数据来源是什么？**（公告、研报、传闻）
4. **口径是否一致？**（额定/峰值、电机/模组）
5. **能否找到反方证据？**（竞品参数、行业趋势）
6. **如何映射到财务影响？**（成本、ASP、需求、产能）
