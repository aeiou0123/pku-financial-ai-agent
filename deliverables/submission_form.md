## 4. 项目公开介绍（287/500 字）

```
机器人产业链每天都在发生技术突破，但工程信号离金融价值有多远，卖方研报各说各话，买方难以判断。Claim2Value 是证据驱动的金融分析 Agent：把产业链公司的技术宣称逐条对回公告原文验证分级，验证结论经门控、工程口径归一化、经济假设映射、因果批判四层处理，真实传导进财务三情景估值；每个数字可回溯到公告具体页码，每一步可审计、可复算。它不输出目标价，而输出"市场隐含预期与已验证证据"的对照表，把判断权留给分析师。已跑通绿的谐波、双环传动两家全链路，证据网络覆盖 11 家上市公司 51 条 Claim（47 条公告原文级验证），140 项回归测试全过，离线可复现。
```

## 5. 核心创新点（逐条点击"+添加一条"粘贴，共 5 条）

```
验证-估值串联传导：验证置信度直接调整经济假设再进DCF，验证强度决定估值强度，不是两套并存数字
```
```
因果批判层：自动生成替代解释与待补反事实清单，把行业β与公司α分开，不可归因部分透明扣减置信度
```
```
证据分级与口径审查：公告/研报/媒体显式分级不越级引用；口径错位自动捕获（实证：券商把半年报累计误标为单季，被系统捕获并以官方原文纠偏）
```
```
工程口径归一化：额定vs峰值扭矩、电机vs模组、不同减速比档位先归一再比较，不可比明确标记绝不硬算
```
```
反向DCF交付物：不输出目标价，输出"市价隐含销量预期=可验证假设的16.7倍"式对照表，合规边界内支持买方决策
```
