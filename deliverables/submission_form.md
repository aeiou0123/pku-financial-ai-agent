## 1. 项目名称

```
Claim2Value：面向机器人产业链的本地研究工作台
```

## 2. 一句话摘要

```
把企业技术表述逐条对回公告原文，保留口径、出处与缺口，再核验财务与两期盈利变化。
```

## 3. 项目公开介绍（不超过 500 字）

```
机器人产业链的技术表述常省略测试条件、比较对象或统计口径。减重 30% 若不说明是否同等出力、比较哪一代产品，结论就无法复核；客户名单表明覆盖关系，也不自动证明订单、收入或利润兑现。研究者需要把技术参数、订单线索与财务预测分开看待。

Claim2Value 是一个本地研究工作台，把技术表述、公告原文、口径检查与工程到财务的假设放在同一处。它提供三类任务：观点审查把叙述拆成待检查条件并在材料中检索支持与反证；财务整理从年报提取候选，核验报表范围与期间口径后解释两期盈利变化；策略回测先用本地规则体检行情，再按明确参数计算净值、回撤与同费率基准。

每条财务候选必须给出逐字原文摘录，且摘录要能在其标注的文件页中找到，否则拒收并留档。报表口径按原件页序识别"合并／母公司"标题并跨页继承，声明与所在表标题冲突的候选同样拒收。财务核验、数据体检与回测均在本地执行，不需要模型密钥。已跑通绿的谐波 2024 年年度报告 13 页：加入口径校验后重跑收下 30 条候选，数值全部与原页参考表一致、覆盖 24 个目标口径。
```

## 4. 核心创新点

```
引用锚定：每条财务候选必须附逐字原文摘录且能在标注页中找到，否则代码级拒收并留档，不是仅靠提示词约束
```
```
报表口径校验：按原件页序识别合并／母公司标题并跨页继承，声明与所在表标题冲突的候选拒收；标题不明时不判定
```
```
单位相邻校验：数值与单位须在原文中明确相连，避免把"台"误读成"万台"；解释中脱离摘录的数字标记待核对
```
```
无前视回测：按信号次日执行，因子按可得时间屏蔽当日收盘后才可得的行，运行前把声明参数写入实验登记
```
```
失败可恢复与如实留痕：中断后按已完成批次续取；被拒提案、未采用候选与原因一并展示，缺口不因重跑成功而消失
```
