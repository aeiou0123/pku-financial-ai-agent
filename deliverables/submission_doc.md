# 一、我们要解决什么问题

机器人产业链每天都在发生技术事件：减速器扭矩密度提升、丝杠量产、新订单落地、募投扩产。这些工程信号与金融决策之间存在信息断层：

1. **人肉翻译**：工程宣称到财务影响靠人工转译，慢且不可复算；
2. **口径打架**：卖方研报各说各话——券商降价假设（ASP 1,500 元/台）已被绿的谐波 2024 年实际 ASP（1,293 元/台）击穿；
3. **真假难辨**：买方无法区分"已验证证据"与"公司话术"。

# 二、产品：从 Claim 到估值的可信流水线

Claim2Value 把公司技术宣称逐条验证，并让验证结论**真实传导**进估值：

**Claim → 验证（规则+LLM 双轨）→ 门控 → 工程归一化 → 经济映射 → 因果批判 → 财务三情景**

四条核心产品主张：

- **传导而非并存**：验证置信度直接调整经济假设再进模型；
- **逐条溯源**：每条假设带证据等级、置信度与 provenance 链，可回溯公告原文页码；
- **透明打折**：因果批判层区分行业 β 与公司 α，置信度从 0.5 打到 0.32，折扣写在输出里；
- **三栏输入**：每个模型输入分"历史锚点 / 人工假设 / 计算结果"，来源指纹可查。

# 三、证据网络：11 家公司 · 51 条结构化 Claim

Claim Bank 覆盖机器人关节模组产业链 11 家上市公司（绿的谐波、双环传动/环动科技、步科股份、中大力德、鸣志电器、柯力传感、五洲新春、贝斯特、恒立液压、国茂股份、秦川机床），共 51 条结构化 Claim：

- **47 条已验证**（公告原文级，页码定位 + 内容指纹，含双源互证）；
- **4 条待验证**（显式标注疑点与驳回路径，不假装验证过）。

2026-09-09 终验实证：11 条 Claim 经巨潮资讯网公告原文逐字核对升级；其中 SH_003 发现券商研报将"2025H1 累计收入 3.49 亿"误标为"Q2 单季"，被口径审查捕获并以双环传动半年报原文（p.14，348,990,082.38 元，+35.66%）纠偏——这是"口径偷换检测 → 官方原文纠偏"链路的完整实证。

# 四、深度案例：一条 Claim 的一生（绿的谐波）

以"关节模组减重 30%"宣称为例（`python app.py` 实跑）：

1. **输入与检出**：规则检出限定词缺失（原文"同等出力情况下"被丢）→ 部分成立，置信度 0.3；
2. **门控与归一化**：门控放行 → 14 行参数归一化，4 行可比、10 行明确标记不可比；
3. **经济映射**：扭矩密度→渗透率 -10.26%（证据 high）；重量→BOM 成本 -5.47%（弹性经招股书材料成本证据校准）；
4. **因果批判**：12 个替代解释、14 条待补反事实，置信度 0.5→0.32；
5. **财务三情景 EV**：base 43.4 亿 / upside 69.4 亿 / downside 15.8 亿（原型情景、非投资建议）。

# 五、通用性：同一条链路，换一家公司

双环传动全链路移植：rv/gear 双产品线自动识别（`detect_product_lines`）、ontology 变体、规则级 `product_line_scope`，三情景 EV 72.7 / 122.9 / 19.0 亿（RV 参数按环动科技招股书实际均价 2,653–3,209 元/台校准）。端到端回归测试随附（`tests/test_shuanghuan_chain.py`）。

# 六、反向 DCF：诚实的估值观

绿的谐波市价 512.96 亿（2026-09-04）vs 证据支持的模型三情景 EV 0.9 / 30.8 / 58.5 亿。我们不做目标价，而是反向量化差距：**市价隐含的销量预期 = 可验证 base 假设的 16.7 倍**。差额 ≈ 市场为"人形机器人量产期权"支付的价格。买方拿着"隐含预期 <-> 已验证证据"对照表自己判断赔率——这是产品化的合规分界线。

# 八、商业潜力

- **市场**：TAM 上限锚为谐波环节远期空间 71–603 亿（GGII 与高盛双口径并列）；SAM 按买方/卖方/产业三类客户切分；SOM 2–6 亿/年（证据服务订阅）；
- **竞品缺口**：现有金融数据终端与 AI 投研工具无证据分级传导、无双账本溯源、无因果批判、无工程口径归一；
- **定价**：按"证据深度"三档分层（基础验证 / 证据链报告 / 定制链路）；
- **落地路径**：绿的谐波案例报告获客 → 买方研究员工作流嵌入 → API 化输出；验证期目标 5 家付费试点。

# 九、路线图

- **0–6 月（验证期）**：Claim 终验 47/51 已完成（余 4 条待厂商 datasheet）；5 家付费试点；案例报告产品化；
- **6–18 月（放大期）**：实时检索上线（evidence_retriever）、专利核验全覆盖、覆盖扩展至 50 家公司；
- **18–36 月（规模期）**：平台化 + API 输出、跨行业 ontology 复用、证据资产订阅化。

# 十、合规边界（三条红线）

1. **非投资建议**：所有估值输出常驻"原型情景、非投资建议"标注；悲观情景常驻，对冲卖方一致预期的系统性乐观偏差；
2. **证据不越级**：券商研报/媒体转述显式降级标注，不与公告原文级证据混用；
3. **来源全标注**：每个数字带来源与内容指纹；AI 参与部分按大赛要求如实披露。
