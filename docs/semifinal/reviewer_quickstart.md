# Claim2Value 本地操作与证据导览

版本：2026-10-10。本轮结果以总包05_技术证据/本次验收.json和部署验收.json为准，旧云端记录不代替本机验收。

## 启动

推荐Python3.12。Windows双击start_demo.bat；Linux执行bash start.sh。脚本建立独立.venv-demo并安装固定版本依赖，首次需联网；版本齐备后跳过安装，可离线运行。默认无需账号或模型密钥。

浏览器打开http://127.0.0.1:8501。默认关闭使用统计收集，不调用外部模型API；点击来源链接会访问外站。启动窗口Ctrl+C停止。端口占用时用.venv-demo的Python手动启动streamlit run app.py --server.port 8502 --browser.gatherUsageStats false。本机localhost不是在线评审地址。

## 操作

1. 财务记录（默认页）：选择公司和期间，两年数据按指标并排，单位百万元。下载JSON保留元单位原值、真实披露日和定位。当前已核样本为绿的谐波34条年度合并记录；步科和双环传动显示缺口。2024比较数取自2025年报，披露于2026-04-23。
2. 声明核查：填写企业声明、引用原文和选填出处，点击“核查声明”。结果提示缺证、口径或限定条件问题；自定义输入不计算估值。空声明或错误链接清除旧结果。
3. 情景测算：选择绿的谐波或双环传动，点击“计算情景”。“原文与出处”查看引用，“测算与假设”查看亿元单位结果、固定参数和待补证据，“下载报告”保存本次记录。切换公司后清除旧显示，需重新计算。2025期是原有假设，不作为当前预测。
4. 导出：核查和财务报告保留输入与限定；原文分享前确认使用范围。批量CSV说明见batch_evidence_guide.md，模板为合成案例。

## 证据与边界

05_技术证据/证据索引.md对应实际案例、开发复测、财务来源、部署及技术题复现。哈希只验证本地字节，原页核验另有记录。页面不上传PDF、不实时检索、不调用在线语义模型、不验证技术升级因果效应。

开发库98条扰动来自19个原家族，本次87/98命中；它曾用于规则开发，不是独立业务准确率。11条未命中保留，规则分数不是校准概率。

CSMAR客户端导出留在本机私有目录，定义与披露日仍有缺口，不随部署分发、不自动升级Claim Bank或校准预测。真人试用须负责人真实完成，浏览器自动操作和AppTest不等于真人反馈。

首次安装失败请检查网络和Python版本后重试；本包不含离线安装轮子。本次Windows运行记录见部署验收，其他系统历史运行分列。
