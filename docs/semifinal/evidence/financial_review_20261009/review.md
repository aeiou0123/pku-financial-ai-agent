2024 年报 PDF 第 7 页（印刷页 7，262 页原件）披露营业收入 **387,411,303.84 元**、归属于上市公司股东净利润 **56,168,149.88 元**。旧模型输入误写成 3.87 与 0.561681 十亿元，约放大十倍；已修正为 **0.38741130384** 与 **0.05616814988** 十亿元，并把定位从 meta 注释改为原 PDF 页码。

同步修正 `data/processed/green_harmonic_model.xlsx` 的 Inputs 页 C2、C3、G2、G3、H2、H3。使用电子表格导入/编辑/导出流程，修改前后渲染核对；只增加两项数值显示精度和 C 列宽以显示完整值。全部其他单元格数值、五个页签与冻结窗格经读取比较一致，未发现公式错误。工作簿三种情景表未改变。

`data/processed/public_financial_green_2024_2025.csv`：2025 年报中的 2024、2025 年合并报表，17 个指标各两年，共 34 行。每行保留原字段、元单位、合并口径、年度/时点类型、公告日、修订口径、原文件 SHA-256 和 PDF 页码。逐页对照图像与抽取文本，页码与数值复核见 `source_review.json`。

公告日为 2026-04-23：其中 2024 比较栏也使用这一原件公开日，不能冒充 2024 年末已知数据。2024 收入与归母净利润另与 2024 年报 PDF 第 7 页独立交叉核对。区分合并总净利润与归母净利润、合并总权益与归母权益，不把母公司表混进合并表。

两年「资产－负债－总权益」差额均 **0.00 元**；元与十亿元按 Decimal 转换，毛利率分别约 **37.5401%（2024）** 与 **36.9052%（2025）**。具体原数、计算值、单位和状态见 `quality_report.json`。这些是历史指标，没有推断技术升级的因果效应。

## 接收流程与边界

下载原表 → 私有接收目录保留原件 → 指纹与表头清点 → Codex 根据真实字段说明明确映射 → 标准长表检查 → 对照公告人工复核 → 另立经过审查的模型接入变更。

本轮完成离线原件清点和标准长表检查，**未实现任意 CSMAR 宽表自动映射**。标准化结果不自动覆盖财务预测或比赛持仓。数据字典到达后，按实际列名和单位补映射，不猜测官方字段编号或 SDK 接口。
