# 批量证据核查：实际可执行路径

2026-10-03。适用于已经取得原件、需要批量运行本地规则的证据整理。无需 Qwen/Kimi 密钥。CSV 模板四行均为合成案例，不能作为真实金融效果证据。

## 填写

复制 `templates/evidence_batch.csv`，用 UTF-8 CSV 保存。每批最多 100 条、5MB。

| 字段 | 填写方式 |
|---|---|
| case_id | 唯一编号，字母、数字、下划线或短横线，最多64字符 |
| claim | 待核查的一条声明；保留金额、时间、型号和限定条件 |
| source | 已取得原件中的相关原文；空缺原文应留空，不由模型编造 |
| source_url | 可选 HTTP(S) 原件链接；链接仅被记录，不自动下载或认证 |
| source_locator | 可选页码、表名、版本、获取日期；记录对应原件文件路径 |

含逗号、引号或换行的字段须按 CSV 转义；推荐用表格软件导出 UTF-8 CSV。不要粘贴完整付费数据库、校园登录信息、密钥或账户凭据到公开仓库。

## 运行

先按评委操作导览启动一次应用，安装环境后在工程根目录运行：

```bash
.venv-demo/bin/python scripts/review_evidence_batch.py --input docs/semifinal/templates/evidence_batch.csv --out batch_result
```

Windows 将 Python 路径改为 `.venv-demo\Scripts\python.exe`。将模板路径换成自己的 CSV 即可。每次使用新的结果目录，已有记录不会被覆盖。

每条合法输入得到 JSON、Markdown，批次得到 `batch_index.json`：原文与出处、规则结果、缺证状态、输入与代码 SHA-256。单行网址或声明无效时记录错误并继续处理其余案例。退出码 0 表示输入处理完成，1 表示有无效行，2 表示文件结构错误；0 不表示声明已经得到证实。

## 人工复核与回填

先逐项核对原件日期、型号、单位、工况、页码和来源，再决定 Claim Bank 状态。此工具不写入 Claim Bank，不认证 PDF，不调用在线模型，也不把新文本套进固定公司估值。`abstain` 表示规则不能确认，不能写成“验证通过”。

已实现合法千分位及注册单位的等值归一化、明确 `X型号` 分段中的数值归属。未实现任意格式表格理解、多指标语义绑定、工况自动认证及一般单位推理。完整原文保存在报告中，归一化仅用于内部比对。
