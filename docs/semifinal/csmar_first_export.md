## 先做一个小包

在你已能访问的 CSMAR 页面搜索「财务报表」或「上市公司财务报表」。不同学校版本的菜单可能不同，以你账号实际界面为准；当前未核实官方 SDK 与具体字段代码，不要求你接 API。

筛选 **绿的谐波，证券代码 688017，报表截止日期 2024-12-31，合并报表，年度累计口径**。分别导出资产负债表、利润表、现金流量表的原始 XLSX 或 CSV，以及各表字段说明/数据字典。只有一个公司一个年度，字段能全选就全选，最省事。优先保留导出页面自带的字段说明。

**无需自己改列名、换单位或清洗。** 将 3 份原表和字段说明放在同一个文件夹，压缩后上传现有私有 Drive 文件夹或本对话即可。商业数据库原始导出保留在私有目录，公开 GitHub 只提交接入代码、检查结果摘要及许可允许的索引。

最小字段清单如下；若界面使用英文/编号列名，仍按原样导出，同时保存对应中文说明。

| 表 | 优先字段 | 用途 |
|---|---|---|
| 三张表共用 | 证券代码、公司名、报表截止日期、报表类型（合并/母公司）、期间口径、金额单位、币种、公告/披露日期、版本或调整标识 | 保留主体、期间、单位、可用时间和修订口径 |
| 资产负债表 | 资产总计、负债合计、所有者权益合计、归母权益、货币资金、应收账款、存货、应付账款、固定资产、短期借款、长期借款、一年内到期非流动负债 | 勾稽、资金与营运资本参考；归母权益不能代替总权益做资产恒等式 |

公告日期或版本标识若在当前表选不到，先交其余原表和字段说明，并说明缺了哪项。我从公告核对补充；不会把报表截止日自动当成公开日。空白、横杠等缺失值按原样保留，不填 0。出现多个修订版本都保留，不擅自删掉。

## 你可以使用的本地文件夹

解压接收包，得到 `Claim2Value-workspace`，可放在 `C:\Claim2Value-workspace` 或任意目录。把三张表放进 `raw/A_financial/`，字段说明放进 `raw/dictionaries/`。我当前工作在本会话工作区，不能直接读你电脑的 C 盘；把原导出上传后，我在这里映射、检查并回传结果。

不运行代码也能交资料。已有 Python 3.11 或更新版本时，可在解压目录运行：

```bash
python scripts/financial_intake.py init --workspace .
python scripts/financial_intake.py inventory --workspace .
```

`inventory` 保存原始文件不动，并输出文件名、指纹、CSV/XLSX 开头几行。XLSX 预览需 `openpyxl`，未安装仍记录文件指纹和依赖缺口。工具当前不猜 CSMAR 字段代码，也不自动将宽表转成长表；收到实际字典后由我补明确映射。原始数据请先上传，不必为了安装依赖耽误导出。

接收包中的公开年报样本可自测：

```bash
python scripts/financial_intake.py validate --workspace . --input example/public_financial_green_2024_2025.csv --source-root . --as-of 2026-10-09
```

结果写入唯一的 `runs/时间_标识/`，含原始长表快照、标准化人民币金额、JSON 检查报告和说明。检查不覆盖预测与估值，不改变技术题名单；原件指纹一致也不能代替来源和页码人工复核。
