# 真实运行录屏脚本（目标4分半）

这是录制安排，不是已经完成的视频。最低1280×720；字幕或人声清晰。保留未经剪辑的原录屏。计算快放时标实际用时，禁止把其他运行结果接到本次输入后。

| 时间 | 画面操作 | 说明内容 |
|---|---|---|
| 0:00—0:30 项目与功能 | 显示队名、Claim2Value、录制日期；打开能力范围 | 产业研究中技术声明的口径和证据问题；本次本地规则模式，不调用外部模型 |
| 0:30—1:20 真实运行 | 选择绿的谐波→运行→查看输入、规则与来源 | 限定条件缺失；页码待核与来源状态；不要说减重声明已完全证实 |
| 1:20—1:55 真实运行 | 切双环传动→重新运行→确认公司 | 参数绑定不同公司；客户覆盖不等于批量收入；固定假设情景不等于因果效应 |

| 4:00—4:30 局限与适用 | 能力范围与缺证/失败记录 | 人工核原文、未实现实时检索、未完成真人试用；新数据和技术题结果待补 |
