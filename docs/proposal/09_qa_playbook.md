# 第 9 章 答辩问答预案（Q&A Playbook）

> 用途：评委高频问题 + 标准答法。每题给"30 秒口播版"和"追问防线"。
> 数字口径以仓库 main 分支为准（基线见 06 章）；所有引用均可回溯到
> Claim Bank / benchmark 报告 / 延迟报告。

---

## Q1 你们的准确率高吗？

**口播 30 秒**：
我们不用"准确率"这个词包装自己。自建 98 题扰动 benchmark 显示：裸 LLM 在金融
口径判别上只有 62.5%（Claude）/65.3%（GPT）——直接用在投研上会出事故。我们的
规则层在 LLM 之前做确定性检查，合并后 91.8%/90.8%，其中"口径偷换"从 12% 提到
71%，"限定词删除"从 32% 提到 95%，且修复后误伤归零（`benchmarks/pipeline_report.md`）。

**追问防线**：
- 问"91.8% 是什么集上的"→ 自建扰动测试集（6 类金融典型陷阱），非业务最终准确率，
  我们如实标注为"benchmark 判别准确率，非业务准确率"（03 章原文）。
- 问"剩下 8% 怎么办"→ 三层兜底：规则层漏检的由 LLM、再不行 abstain 拒答 +
  人工核验人必填（Claim Bank 硬校验），宁可不答不瞎答。

## Q2 和 Wind / 同花顺 iFind / AlphaSense 有什么区别？

**口播 30 秒**：
他们是检索和摘要工具——帮你"找到信息"；我们是对"结论"做验证和归因——帮你
"判断信息能不能信、值多少钱"。我们不存数据，我们判数据：一条技术 claim 进来，
先过证据分级和 6 类规则检查（口径偷换/限定词缺失/数值矛盾/来源降级/时间错位/无证据），
再过因果批判层区分"行业β和公司α"，最后才进估值。这个纪律是他们没有的。

**追问防线**：
- 问"Wind 加个 AI 功能不就做了"→ 这正是 06 章风险表里的"竞品复制"项；我们的对冲
  是证据链数据资产 + 审计留痕 + 开源 pipeline 已建立的信任，以及 98 题 benchmark
  的方法论壁垒（知道该测什么陷阱本身认知成本高）。

## Q3 换个行业还能用吗？是不是只为机器人产业链定制的？

**口播 30 秒**：
三层架构里，验证链（规则层+LLM）完全通用，文本进判定出；证据结构（Claim Bank）
是公司无关的。工程→经济映射由 ontology JSON 驱动、零硬编码，换行业换 ontology
和案例参数即可。实证：同一条 `run_financial_chain` 已跑通两家公司——绿的谐波
（harmonic/joint 两条产品线）和双环传动（rv/gear 两条产品线），双环全链路三情景
EV 72.66/122.89/19.04 亿元（PR #20，含 e2e 测试；PR #28 按环动招股书校准 RV 参数后口径）。

**追问防线**：
- 问"为什么不现场演示换一家"→ 双环就是第二家；Claim Bank 已有 11 家公司
  51 条 claim（中大力德/鸣志/柯力/五洲新春/贝斯特/恒立/国茂/秦川等），验证层
  对这些公司可直接工作，估值层移植需要该公司财务锚点（半人工，约 1-2 天/家）。
- 问"通用性边界"→ 工程参数映射的弹性系数是按减速器标定的，跨行业需重新标定，
  这在 06 章路线图中如实标注为移植成本。

## Q4 模型 EV（0.9–58.5 亿）和市场市值（513 亿）差逾一个数量级，模型错了吧？

**口播 30 秒**：
这不是模型的 bug，是我们产品的核心输出之一。简化 DCF 只算"可验证证据支持的
基本面价值"，市值里含人形机器人叙事预期。我们不硬凑市值，而是反向量化差距：
反向 DCF 显示，市价 513 亿隐含的销量预期约为我们 base 假设的 **16.7 倍**
（`reverse_dcf`，PR #19；PR #28 参数复核后口径——税率/成本按年报与招股书锚定后，
差距反而更大，说明原假设其实偏乐观）。"市场有多乐观、证据支持多少、差距 94% 在哪"——
这个对照表正是买方研究员最想要的交付物。

**追问防线**：
- 问"那你们到底看多看空"→ 我们不做投资建议（08 章合规红线），只交付"隐含预期
  ↔ 可验证证据"的对照，决策权在人。
- 问"反向 DCF 可靠性"→ 单维度（销量倍数）二分求解，口径边界在 PR #19 如实标注
  （市值近似 EV、其余参数保持 base）。

## Q5 LLM 幻觉怎么防？

**口播 30 秒**：
三层防线。第一层：规则层确定性检查可覆盖即覆盖，直接覆盖 LLM 的 verdict，
规则注册表可审计（每条规则有 rule_id/触发条件/依据）；第二层：无证据直接
abstain 拒答，本地演示里就能看到"拒答"是默认行为而非失败；第三层：Claim Bank
核验人必填硬校验 + 全链路推理留痕，任何人可以拿 excerpt 回源文件逐字核对。

**追问防线**：
- 问"规则层误伤怎么办"→ benchmark 里量化跟踪 hit→miss（误伤），修复后归零；
  这是把"AI 幻觉"从口号变成可测指标的方法论。
- 问"为什么规则层能提升 29 个点"→ 金融口径陷阱（额定/峰值、归母/扣非、累计/单季）
  是确定性模式，字符串匹配+数值归属比注意力机制更可靠（pipeline_report 方法论节）。

## Q6 数据哪来的？实时吗？

**口播 30 秒**：
证据以公开披露为主（年报/招股书/公告，页码级留痕）+ 券商研报转引（标注降级），
51 条 claim 里 36 条已验证到页码/章节级。实时检索在 roadmap（evidence_retriever），
当前故意用本地缓存——避免外部服务成为 Demo 单点，离线可复现（本地全链路 p50 4.3ms，N=30）。

**追问防线**：
- 问"研报数据错了怎么办"→ SH_003 是活案例：研报把半年报累计数标成单季，我们的
  caliber 复核抓到疑点，结论"引用以官方披露为准"写进了 Claim Bank notes。
- 问"PDF 抽取错位"→ 纳博特斯克 RV-20E 行因列错位被降级为 not_comparable 移出
  基准池（PR #20）——宁可缺样本，不污染基准。

## Q7 商业化凭什么？谁会付钱？

**口播 30 秒**：
卖方分析师是首要用户：证据回溯、假设核验、报告审计三个痛点（02 章）都对应已交付
能力。SAM 测算 2-6 亿/年（[C8]，标注性假设）；定价锚慧博 0.9-2 万/年到 Wind
3.98 万/年之间，三档定价（开源版/专业版/机构版，05 章 5.7）。卖点不是功能多，
是"可审计"——研报合规压力越大，证据链越值钱。

**追问防线**：
- 问"Wind 降价/免费怎么办"→ 我们的成本结构是 LLM API + 工程，规则层无 API 成本；
  且开源策略是获客而非卖软件（06 章商业模式节）。
- 问"客户验证过吗"→ 如实回答：尚无付费客户，C7 效率实测和试点在路线图 M1-M4，
  不假装已有 PMF。

## Q8 团队分工和这个项目的关系是？

**口播 30 秒**：
按 07 章 PR 对应表回答：验证与证据链（经济金融组）、pipeline 与 benchmark（工程
组）、Demo 串联化（合作者 PR #17）、商业潜力与项目书（本项目主线）。全部进度在
GitHub PR 历史里公开可查，审计留痕本身就是我们产品的实践。

**追问防线**：
- 问"AI 写了多少"→ 如实：AI 承担初稿与初核，人承担口径裁定与终验（如 SH_003
  口径结论由人工复核确认）；这也是我们产品主张的工作流——AI 生成，规则验证，
  人工兜底。

## 使用纪律

1. 只讲有出处的数字；被追问拿不准的，回答"这个在 Claim Bank/某报告里有记录，
   我可以展示原文"——宁可现场翻，不现场编。
2. 所有估值表述必须带"原型情景、非投资建议"限定（08 章红线）。
3. 新问题记入本文件附录，形成迭代。
