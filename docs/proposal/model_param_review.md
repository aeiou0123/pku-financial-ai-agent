## 四、Ontology 弹性系数复核（6 条规则）

| 规则 | 弹性 | 评价 |
|---|---|---|
| torque_density→share | 0.30 | 🟢 方向正确、量级保守、已声明"可调假设非实证"；"份额高位边际递减"注释恰当 |
| power_density→share | 0.30 | 🟢 同上；"parameter_table 缺功率密度列"的限制已如实标注 |
| efficiency→unit_cost | 0.20 | 🟡 逻辑链（效率差→能耗差→TCO→议价压力）成立，但映射到"自身 unit_cost"是代理处理，语义上更接近 ASP 让利压力。建议在 note 中写明，或改映射 asp。不阻塞 |
| backlash→asp | 0.15（+30 arcsec 门槛护栏） | 🟢 设计良好：方向负（背隙小→价值高）、有量化护栏防误触发 |
| weight→unit_cost | 0.50 | 🔴 **唯一建议改数值的规则**。精密减速器成本中加工/装配/检测占大头，材料占比低——环动招股书：钢材采购价 6.14-6.65 元/kg，一台 4.7kg 减速器的钢材直接成本仅约 30 元量级（即使计入毛坯件 81-119 元/只与外购配件）。重量差 10% → 材料成本差远小于 5%。建议弹性降至 **0.2-0.3**，或注明"0.5 含加工规模效应代理，非纯材料逻辑" |
| backlash→addressable_market | 定性 | 🟢 qualitative_only 处理正确 |

**RV 专属标定问题（已知项）**：双环版 ontology 目前沿用谐波标定。本次从环动招股书拿到了 RV 真实锚点（ASP 2,653-3,209 元、毛利率 35-42%、重量-成本弹性应以 RV BOM 重估），经济金融组复核时可直接用这三个数做 RV 专属标定，不必从零找数据。
