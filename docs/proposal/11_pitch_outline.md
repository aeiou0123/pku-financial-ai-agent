## P2 痛点：信息断层（45s）

- 左图：产业链技术信号（减速器/丝杠/电机公告）→ 右图：金融决策（买/卖/持有）
- 中间断层的三个具体表现（02.2/02.3）：
  1. 工程宣称到财务影响靠人肉翻译，慢且不可复算；
  2. 卖方研报口径不一（5.3.3：券商降价假设已被现实击穿）；
  3. 买方无法区分"已验证证据"与"公司话术"。
- 四大缺口各配一个实例（02.3）
- 建议图表：断层示意图 + 一条真实研报口径打架的对比

## P3 产品：四层流水线（60s）

- 核心图：**Claim → 验证 → 门控 → 工程归一化 → 经济映射 → 因果批判 → 财务三情景**
- 关键卖点一句话各一（03.3 四条产品主张）：
  - 验证结论**传导**进估值（不是两套并存数字）；
  - 每条假设带证据等级 + 置信度 + provenance；
  - 因果批判层透明打折（行业β vs 公司α）；
  - 输入三栏溯源（历史锚点/人工假设/计算结果）。
- 对应章节：03_product

## P4 证据网络：11 家公司 51 条 Claim（45s）

- 地图式公司分布：绿的谐波/步科/双环（含环动科技）/中大力德/鸣志/柯力/五洲新春/贝斯特/恒立/国茂/秦川
- 数字卡片：**51 条结构化 Claim，47 条已验证（公告原文级，页码+内容指纹），4 条待终验（带显式定义疑点与驳回路径）**
- 强调诚实口径：待验证的不假装验证过——47/4 分级本身就是产品可信度的演示
- 对应章节：04.1–4.2；数据 `claim_bank_filled.json`

## P5 深度案例：一条 Claim 的一生（90s，重头戏）

- 用 GH_001 实跑全程（`python app.py` 截图/录屏帧）：
  1. 输入："关节模组减重 30%" → 规则检出**限定词缺失**（"同等出力情况下"被丢）→ 部分成立、置信度 0.3；
  2. 门控放行 → 14 行参数归一化（4 可比 / 10 明确标记不可比）；
  3. 经济映射：扭矩密度→渗透率（-10.26%，证据 high）、重量→BOM 成本（-5.47%，弹性经招股书材料成本校准）；
  4. 因果批判：12 替代解释、14 条待补反事实，置信度 0.5→0.32；
  5. 三情景 EV：**43.4 / 69.4 / 15.8 亿**（标注"原型情景、非投资建议"）。
- 一句话点题："验证强度决定估值强度——这条链路里没有'无条件相信'这个数字。"
- 对应章节：04.3–4.4；脚本 `10_demo_script.md`

## P6 通用性现场证明：换一家公司（45s）

- 同一链路换 fixture：双环传动 rv/gear 双产品线自动识别
- 三情景 EV：**72.7 / 122.9 / 19.0 亿**（RV 线按环动招股书实际均价校准后）
- 一句话："不是专用工具，是通用 Agent——产品线泛化（`detect_product_lines`）、ontology 变体、规则级 `product_line_scope` 全是代码层实现，有回归测试锁定。"
- 对应章节：04 章双环节；`tests/test_shuanghuan_chain.py`

## P7 反向 DCF：诚实的估值观（45s）

- 核心图表：市价 512.96 亿 ↔ 模型三情景 0.9 / 30.8 / 58.5 亿 ↔ 隐含销量预期 **16.7×** base 假设
- 三句话讲清（5.5.3 / 4.4.2）：
  1. 差额 ≈ 市场为"人形机器人量产期权"付的价格；
  2. 我们不做目标价，做**隐含预期 ↔ 已验证证据对照表**；
  3. 买方拿着对照表自己判断赔率——这是产品化的合规分界线。
- 对应章节：05.5；`reverse_dcf()` 实测 16.66×（PR #28 参数复核后口径）

## P8 工程可信度（30s）
