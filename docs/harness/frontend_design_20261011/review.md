# 研究工作台界面调整 · 2026-10-11

首页改为按行排列的研究任务，直接列出所需材料和输出。去掉口号式标题、三张并排大卡片和满宽蓝色按钮。工作区、教程与成果页统一使用白底、深灰正文、细分隔线和小圆角；宋体标题与中文无衬线正文区分阅读层级，棕色只用于任务编号和选中标记。字体使用本机回退，不加载外部字体。

## 参考与取舍

实际浏览了 [Anthropic 关于生成式前端设计的文章](https://claude.com/resources/articles/improving-frontend-design-through-skills)、[NN/g 视觉层级指南](https://www.nngroup.com/articles/visual-hierarchy-ux-definition/)及 [GOV.UK 任务清单组件](https://design-system.service.gov.uk/components/task-list/)。这些来源分别讨论默认模板趋同、注意力层级和任务呈现。结合金融研究的材料、出处和输出要求，采用任务列表和底稿式排版；颜色与字体的选择属于本项目设计判断，并非来源认证或用户满意度结论。

- 首页的三项任务仍可直接进入原工作流程；教程入口紧接任务列表。
- 表单、下载与结果沿用原功能，估值和策略诊断按需开启；合成样例和待核证据提示仍清楚可见。
- 工作台使用独立样式，不再叠加固定案例应用的旧主题。
- 手机端任务行纵向排列。修复隐藏工具栏同时藏掉侧栏展开按钮的问题。
- 键盘可通过 Tab 到达任务按钮，焦点可见，Enter 可以进入工作区。此检查不等于完整无障碍认证。
