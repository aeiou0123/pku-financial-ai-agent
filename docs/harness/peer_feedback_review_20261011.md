## 反馈对应修改

| 反馈 | 改动与验收 |
|---|---|
| 长报告在旧本机解析上限被截断，无法判断上下文 | PDF本机上限1,000页、文字1,000,000字符；默认财务单批6,000原文字符。显示解析量、预计批数和逐批覆盖；上下文或输出超限时拆小，仍失败则保留缺口。 |
| 小连接测试成功，研究请求超时 | 研究等待30—600秒、默认240秒；临时错误有限重试、默认最多再试2次。显示尝试次数与等待设置，重试计入预算。连接测试仍一次30秒。 |
| 有完整JSON却因代码块或说明被拒绝 | 接受唯一完整对象及常见包装；字段重复、多对象、截断、思考过程不能冒充最终结果。可选JSON输出约束，服务明确不支持时在重试预算内撤去约束。 |
| 中间批次失败后不能使用后续结果 | 财务失败批次登记后继续后续；同一输入继续时复用成功缓存。先加载所有成功批次，新额度错误也不会隐藏已完成尾部。部分结果可下载，核对缺口后另行确认才可校验；报告保留覆盖范围。论点审查失败显示已完成条件并可续取。 |
| 日期要求不明显，模型拟计划失败后卡住 | 文件来源登记可直接看到；解释实际披露日与报告期间的区别。缺日期不猜测。可使用本地可编辑模板，按耳机等业务研究起草条件；明确未调用模型、未阅读证据。 |
| DCF空输入显示Python报错 | 空白、非数字、缺项、NaN用中文提示；五年数值允许中英文逗号。显示单位和示例但不自动填预测。 |

16列财务校验、引用匹配、截止日约束和人工核对继续执行。改变输入、模型或覆盖范围后，旧确认不能代表新结果。关闭会话后的跨会话续取入口仍未提供。
