# 第一次使用

需要真实公告练习时，见[已取得的4份原件与输入](real-cases/sources.md)和[实际结果、失败及限制](real-cases/README.md)。可用该目录的下载脚本取得公开原件，保留文件哈希；不要把模型候选直接当已核事实。

双击 `start_harness.bat`，打开 http://127.0.0.1:8510 。首次安装需联网；之后本地计算可离线使用。进入后先选任务，也可以打开“教程与示例”，不填密钥先体验本地计算。样例是合成数据，不能作为真实公司研究或交易结果。

模型与套餐怎么选择，见[连接指南](model-connections.md)；功能、适用人群和实际边界见[工作台用途](product-value.md)。

## 选一个需要解决的问题

| 你的问题 | 首页入口 | 准备材料 | 最终成果 |
|---|---|---|---|
| 某个扩产、产品或技术观点有没有依据？ | 检查研究观点 | 公告、年报、技术资料，实际披露日期 | 支持候选、反证、缺口和引用定位 |
| 财务数字来自哪里，利润为什么变？ | 整理财务数据 | 年报，或16列财务长表和原件 | 核验表、历史比率；满足比较条件时生成盈利变化底稿 |
| 我的策略扣费后表现怎样？ | 测试策略表现 | 日频CSV／Excel价格或因子表 | 净值、持仓、费用、回撤及同费率基准 |

当前工作台整理研究底稿、计算用户确认的情景。自动整理和证据检查依赖你的模型，仍需核对原件；不查询商业数据库，不自动交易。

## 无需API，先走一次样例

1. 首页点“打开教程与样例”。选择“检查研究观点”，保持销量倍数1，点“运行本地样例”。它会用本地工具计算合成业务情景，保存输入与结果。
2. 将销量倍数调到2，再点运行。销量超产能时，会显示约束冲突并暂缓估值。修改滑块后旧结果会隐藏，必须重新运行。
3. 选择“测试策略表现”，点击运行；查看合成净收益和回撤，下载样例记录。它使用20日动量、2只股票和10bps单边费用。
4. 若想学习完整流程，点“用这组样例进入工作区”。材料直接载入，无需先下载再上传；原件和数据也提供单独下载。

教程里的计算不需要模型，没有生成或伪造模型证据。所有假设和限制随结果保留。

## 用自己的材料检查观点

1. 首页点“检查研究观点”，上传自己的文件，填写研究要求、公司和产品范围。问题要具体，例如“耳机产品路线变化是否有订单及盈利依据？”
2. 在“文件来源登记”填写实际披露日和来源类别。材料的公司与产品默认沿用研究对象；同行资料或全公司资料，在“材料适用范围”中按原件调整。读过原件后再逐份勾选确认。
3. 查看检查清单。需要调整时展开“编辑检查清单与检索词”；也可让模型起草。确认清单后，点“审查证据／继续”。自动检查需要在侧栏配置自己的模型。
4. 先下载“待核对事项清单”，逐项处理冲突、缺口和未完成条件；再查看支持候选、反证及原文定位。没有合格证据时保留缺口，不确认错误参数。
5. 只检查观点时，可以直接下载成果。需要估值时再打开“继续做盈利与估值情景（可选）”，自行核对预测参数、采用的证据和业务覆盖范围，再计算。

合成材料演练：公司甲、减速器；第一份披露日2026-01-01，counterevidence文件2026-02-01，来源类别“合成测试”。这些日期只适用于这两份样例。

## 整理财务数据

1. 点“整理财务数据”。从真实报告提取候选需要模型；已有16列长表时可选择“导入已整理财务长表”，同时提供被引用原件。
2. 长PDF可展开“选择年报页码”，填原件页码，例如 `1,6-7,107-116`；留空读取全文。保留公司、单位、报表标题及财务页，未选页不送入模型，结果标明覆盖范围。点击读取后查看范围、候选摘录；再对照原件核对中文列名对应的字段，包括实际披露日、单位、期间口径及更正版本。取不到的字段留空。
3. 人工确认后点击校验。只有部分提取完成时，先看逐批缺口，再另行确认只使用部分候选。报告会保留未完成范围。
4. 两期可比年度数据齐备时，按页面选择期间并生成盈利变化底稿。只得到单期数据不会自动补齐第二年。
5. 现金流估值按需开启。需要五年用户假设，单位元；允许中文／英文逗号，不自动把历史数字变成预测。

合成财务样例载入后默认使用长表导入，可在不配置模型的情况下练习本地核验。

## 测试策略表现

1. 上传CSV／Excel表。要求日期×股票完整覆盖、六位文本代码、已经复权的价格；不把缺价格填零。
2. 表中已使用 `date`、`stock`、`close` 时，会显示匹配的列；展开“核对表格列对应关系”检查。其他列名请手动选择。已有因子还需要含时区的真实可得时间。
3. 明确动量窗口、持仓数、费率和排序方向。研究要求不会自动覆盖这些参数；如调用模型拟定，仍以你确认的页面参数为准。10bps为0.10%单边费率。
4. 先点“检查数据（不调用模型）”，查看并下载数据体检表。修正原始数据后重新上传体检；再核对价格及信号时间并勾选确认，点“校验数据并运行回测”。先看策略与同费率基准，再看回撤、费用和持仓。
5. 多组参数与成本比较按需打开，先声明全部参数。失败组也保留；看过的样本不能当作未触碰留出集。

成交在下一交易日收盘，之后开始计入持仓收益。未模拟涨跌停、冲击成本和成交量约束；输出不能直接当成可实现交易收益。

## 保存、失败与恢复

文件读不出来时，查看“文件／原因／处理方法”表。重新导出原件，或在上传框移除失败文件，再点“读取文件”。能够读取的文件仍列在页面上；失败文件修正前，不能把这批材料送入模型分析。扫描PDF先做OCR并核对页码，加密PDF需提供你有权读取的未加密版本。只改文件扩展名不能转换格式。

连接失败先看处理方法；需要排查时展开“查看脱敏说明”。密钥或套餐权限问题先到服务商核对，账户额度不足时等待恢复；临时服务故障可稍后重试。长任务已完成批次保留，再次继续只请求未完成部分。超时重试可能再次计费。

页面底部先看“结果与下一步”，再切换“报告正文”或“下载文件”。财务校验失败会列出对应CSV行及修正建议；部分处理、约束冲突与合成样例分别提示。可单独下载Excel、报告、持仓或净值，也可下载完整成果ZIP。

报告会列出实际采用的参数、期间与来源。回测报告包含同费率基准；财务比率保留报表范围与更正版本；现金流和业务情景分别列出用户假设。手机上列数较多的表格可在表格内横向滚动，键盘聚焦表格后可用方向键查看。原文摘录与模型意见只显示文字，不自动加载其中的图片或网页。

切换任务或样例会建立新的输入；已经执行的记录留在本机。“成果记录”可在最近200条本机记录中按文件名、研究问题或编号搜索，并按任务类型筛选。选中后查看时间、状态、结果概况和下一步，再预览或下载。清空搜索或把类型改为“全部”可重新查找。不会改写旧快照。ZIP不包含上传原件或模型缓存，但可能包含原文摘录。

材料上传后会先检查空文件、单文件20MB／总量60MB、最多10个文件及名称冲突。修正提示前不会创建新的处理记录或发送模型请求；文件格式、真实日期和口径仍在后续步骤严格校验。扫描PDF需要先完成OCR，本版不会自动识别图片文字。

模型任务中断时，先看脱敏说明与完成范围。相同浏览器会话、相同材料与要求继续时复用成功缓存。关闭会话后，可以重新下载历史输出；当前没有跨会话继续模型任务的按钮。

按钮灰色时按附近列出的缺项补齐。模型连接的小测试成功不保证长任务成功；等待与重试参数在侧栏“模型连接 → 研究请求与分批设置”。真实模型研究质量与真人业务效果仍需单独检验。
