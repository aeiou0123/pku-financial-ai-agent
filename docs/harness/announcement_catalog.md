# 先找原件，再做研究

2026-10-12查收：本机已收索引内1868个目标A股ID的基本信息已齐，安全续取预览为0；公告全文仍未由此接入。详见[增量核验](data-intake.md)。部署包不附商业目录，下面的缺口提示也适用于其他不完整的自有目录。

打开侧栏“资料目录”。本机已有CSMAR目录时，选择研究公司、信息截止日和公告标题关键词；例如双环传动、2024-12-31、`年度报告`。关键词为字面匹配，多个词匹配任一；留空看该公司在截止日前的已收目录。

下载“原件准备清单”，去公司公告页或交易所按证券代码、标题与日期找原件。Excel第二页保留来源文件SHA256与业务JSON行号；它指向本机收到的目录，并不提供凭空生成的公告链接。“目录检索记录”保存这次筛选条件、清单和来源信息，便于核对材料范围。

拿到PDF或可核对文本后，回到“工作区”，选择“检查研究观点”，上传材料并登记实际披露日、来源与适用范围。先核对解析范围，再制定研究计划、审查支持与反证。目录不会直接当全文材料，不会自动升级财务事实或估值参数。

没有检索结果不代表公司没有公告。目录仍有缺口，截止日之后的记录不会进入本次结果；日期或标题冲突暂排除。详情见页面“目录完整性与来源检查”。新用户安装包没有商业数据库文件，默认只演示合成清单，无需API。

此入口当前只支持688017、002472、688160。自有许可的同格式业务JSON放在工作区 `work/csmar_handoff/20261009/raw/C_announcements/`；文件需含 `table`、`rows`、真实公告ID、证券类型及字符串证券代码，保留前导零。页面仅读取白名单公告表，不能将随意改名的CSV当作CSMAR导出。不要分享商业原始文件、登录票据或账号目录；新增导出先交收核对。
