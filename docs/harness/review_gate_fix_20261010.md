# 证据审查按钮禁用反馈与修复

2026-10-10，负责人反馈勾选研究计划后“审查证据／继续”仍为灰色。

原按钮同时要求研究问题、公司、研究计划确认和至少一份符合披露日期／来源确认要求的文件，但页面未在按钮旁解释未满足条件。另发现来源控件键依赖研究问题，修改问题会使同一文件的日期和确认状态丢失。本次未读取负责人浏览器会话或密钥，不能断言其具体缺失哪一项。

修复将未满足的条件直接显示在按钮旁，逐份列出排除理由和可用材料数量，并默认展开未确认的来源。来源声明绑定文件名和内容指纹，修改问题或添加另一份材料保留原声明；改动原文件内容必须重新确认。既有会话控件按旧键迁移。研究计划仍随问题或范围变化重新确认，未知日期与超截止日的文件仍禁止进入审查。

实际验证：15项相关测试通过。Chrome在本机8510的新隔离会话操作上传的两份合成文本，验证计划已勾选但日期未知时阻止审查并显示原因、两份文件确认后按钮可用、修改问题后文件确认保留而计划须重确认，共3项通过。模型审查执行分支由测试替身验证，真实服务商请求为零，未修改负责人现有会话的模型配置。
